Checked and found sound within the inspected paths:

- Fleet invalidation coalescing starts a timer rather than indefinitely resetting it; snapshot polling continues during subscription outages; pane-set changes cancel the previous status subscription.
- Ordinary herdr calls close their sockets on context cancellation, bound response line sizes, validate response IDs and preserve typed protocol errors. The subscription handoff exception is R1-C03.
- Transcript partial lines wait for newline; observed file shrink and inode replacement reset parsing; oversized unterminated lines are discarded until newline. Tool results update their existing cards, and paginated deltas are ordered by revision.
- Lifecycle operations serialize starts, manual restart clears the restart budget, and the watch caps repeated successful automatic relaunches. Reviewed the corresponding restart/resume, lingering-record and launch-refusal tests; R1-C02 describes the missing session-detection case.
- Dialog/draft checks precede prompt delivery; screen-hash mismatch refuses dialog keys; multi-select/form detection routes the UI toward terminal interaction. These remain screen heuristics, not an atomic server-side compare-and-send guarantee.
- Credential comparisons evaluate both hashes, stored sessions bind to the credential digest, expired sessions fail closed, and ordinary request authentication refreshes cookies. Host/origin checks and terminal authentication precede upgrade.
- Terminal output queues are bounded, and the browser intentionally avoids automatic reconnect following an explicit exit/takeover or policy close. Inspected bridge tests cover cooperative child exit and output handling, but not R1-C01's blocked child input.
