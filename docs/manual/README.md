# The crowsnest manual

How crowsnest works and how to use it, written for someone who knows herdr and Claude Code well
and has not read `DESIGN.md`. The same pages are built into the app: open **Help** (on a phone
under **More**, on a desktop in the left rail), press `g` then `m`, or type a question into the
command palette (`⌘K`, `Ctrl K` elsewhere), such as "how do I land a job". A small **?** beside a
view's title or a confusing card opens the right section without leaving the page.

New here? Read [Start here](start-here.md) first: five sentences, one picture, and a five-minute
first session.
